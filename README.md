# DevBoard

DevBoard is a personal developer dashboard designed to help developers
manage projects, tasks, learning progress, and technical notes from a
single interface.

## Features

Planned features include:

- Project management
- Task tracking
- Learning progress tracking
- Developer notes
- Dashboard statistics
- Progress visualization

## Tech Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Chart.js

Currently under development.
